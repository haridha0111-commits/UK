UK Data & AI Fabric — Engineering Lab

A portfolio prototype for a governed, reusable path from public UK source data to curated products, analytics, and evidence-bounded AI.

Scope: FCA market/product aggregates, published semi-annually. This is not a live bank feed, a client delivery, or a deployed NiFi/Iceberg/Trino environment. The local Python pipeline is executable; target-platform services are an architecture design.

Trust controls in the local run

  • SHA-256 source file match against manifest
  • Required source row counts and duplicate keys
  • Non-negative opened complaint counts
  • Closure percentages reconcile to 100%
  • Null contextual rates remain null
  • Failed gates block curated output

Run locally

From the project root, run:

python pipeline/run_pipeline.py

The standard-library runner verifies the manifest, checks source structure and values, creates byte copies in Bronze, normalizes source periods into Silver, and writes Gold CSVs plus data/fabric.db.

Generated assets

  • pipeline/latest-run.json — status, checks, hashes
  • data/bronze/ — checked source bytes
  • data/silver/ — normalized product, context, market tables
  • data/gold/ — half-year change and group totals
  • data/fabric.db — SQLite queryable local lab

SQLite is the simple demo engine; it is not Iceberg and does not prove enterprise-service integration.

Data owner, semantic definition, source version, classification, quality, freshness, lineage and access are required metadata for the enterprise target.

Bounded AI assistant pattern

  • Discover definitions and lineage from the catalog
  • Query only allow-listed Gold views with read-only parameterized SQL
  • Return source, publication period, values, metric definition and caveats
  • Abstain on ambiguity, access denial, failed freshness or missing evidence
  • Human review; no customer decisions or causal claims
Design only — no model connected

Evaluation before pilot

Test metric selection, period filters, nulls, changing denominators, unsupported causes, stale source, access denial, prompt injection, malformed queries, evidence citations, latency and cost.

Use the organisation's AI risk process to set thresholds. This portfolio includes a prompt/tool design but no model results.
